# mealmind

事前に登録した YouTube チャンネルとレシピサイトから、レシピを1件ずつ提案してもらう個人用アプリです。

## できること

| 機能                                                                        | 実装                      |
| --------------------------------------------------------------------------- | ------------------------- |
| 対話でレシピを1件ずつ提案し、「作る / 作らない / 今回はスキップ」を記録する | `suggest` スキル          |
| 提案するレシピの材料を、概要欄やクラシルのページから書き出す                | `suggest` スキル          |
| 「作る」と決めたレシピのメイン食材を、最大3つ選んで記録する                 | `suggest` スキル          |
| 夜ごはん・昼ごはんごとに、ジャンルで候補を絞り込む                          | `scripts/pick-recipe.sh`  |
| 条件に合うレシピ動画を、重み付きで1件抽選する                               | `scripts/pick-recipe.sh`  |
| 登録したチャンネルの動画一覧を取得して保存する                              | `scripts/fetch-videos.sh` |

### 提案の流れ

1. 使いたい食材や料理名を聞く（「おまかせ」でもよい）。食事は夜ごはんとして扱い、「昼ごはん」と言ったときだけ切り替える
2. 重みに従ってチャンネルを選び、その中から条件に合う動画を1件選ぶ。クラシルが選ばれたときは、サイトを検索して1件選ぶ
3. タイトル（リンク）と材料を提示する
4. ユーザーが動画を見て、番号で返事をする
   1. **これを作る** → `recipes.json` に材料つきで登録する
   2. **これは作らない** → `excluded.json` に登録し、以後は提案しない
   3. **今回はスキップ** → この会話の中だけ避ける

お気に入りにするには、`recipes.json` の該当するレシピの `isFavorite` を `true` に書き換えます。

## 必要なもの

- macOS（標準の `bash`、`jq`、`awk`、`od` を使います。追加のインストールは不要です）
- Claude Code
- YouTube Data API v3 の API キー

## セットアップ

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作り、**YouTube Data API v3** を有効にする
2. 「認証情報」で API キーを作る
   - アプリケーションの制限：**なし**
   - API の制限：**YouTube Data API v3 のみ**
3. `.env.example` をコピーして `.env` を作り、キーを設定する

   ```sh
   cp .env.example .env
   # .env を開いて YOUTUBE_API_KEY= の後にキーを書く
   ```

4. 記入例をコピーして、提案元（チャンネル）と好みを設定する

   ```sh
   cp data/sources.example.json data/sources.json
   cp data/preferences.example.json data/preferences.json   # 好みを設定しないなら不要
   ```

5. 動画一覧を取得する（後述）

API の利用は無料です。1日あたりの上限（10,000単位）があり、全チャンネルの一覧と動画の長さの取得で約280単位を使います。

## 使い方

### レシピを提案してもらう

Claude Code で `/suggest` と入力するか、「今日何作ろう」「鶏ももで何か作りたい」のように話しかけます。

### 動画一覧を取得する

```sh
scripts/fetch-videos.sh ryuji   # sources.json の id を指定する
```

`data/cache/videos-<id>.json` に保存されます。新しい動画を反映したいときに、もう一度実行してください（目安は週1回）。

### レシピを1件抽選する

```sh
scripts/pick-recipe.sh                  # キーワードなし
scripts/pick-recipe.sh 鯖 味噌          # すべてのキーワードを含む動画から選ぶ
scripts/pick-recipe.sh --meal lunch     # 昼ごはんとして選ぶ（省略時は夜ごはん）
scripts/pick-recipe.sh 鶏むね --skip <動画IDまたはURL>   # スキップした動画を除く
```

結果は JSON で出力され、`type` は次のどれかです。

| type        | 意味                                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------------------ |
| `youtube`   | 候補の動画（タイトル・URL・概要欄など）                                                                      |
| `kurashiru` | クラシルが選ばれた（サイトでの検索は呼び出し側が行う）。キーワードもジャンルの絞り込みもないときは選ばれない |
| `none`      | 条件に合う候補がない                                                                                         |

## データファイル

すべて `data/` にあります。

| ファイル           | 内容                                                                     | git                      |
| ------------------ | ------------------------------------------------------------------------ | ------------------------ |
| `sources.json`     | 提案元（YouTube チャンネルとクラシル）と重み                             | 記録しない（個人データ） |
| `settings.json`    | 抽選の設定（「作る」を選んだレシピ・お気に入りの重み、再提案しない日数） | 記録する                 |
| `preferences.json` | 使わない食材・使わない調味料・常備している食材・食事ごとのジャンル       | 記録しない（個人データ） |
| `preferences.md`   | 好みの自由なメモ                                                         | 記録しない（個人データ） |
| `recipes.json`     | 「作る」と決めたレシピ                                                   | 記録しない（個人データ） |
| `excluded.json`    | 「作らない」と決めたレシピ                                               | 記録しない（個人データ） |
| `cache/`           | 動画一覧のキャッシュ（再取得できる）                                     | 記録しない               |

`sources.json` と `preferences.json` には、記入例の `*.example.json` があります（記録する）。`sources.json` 以外の個人データのファイルは、なければ空として扱われます。

### 書き方の決まり

データを長く使い続けられるよう、次の形にそろえます。

- 決まった形のデータは JSON、自由なメモは Markdown にする
- すべての JSON に `"schemaVersion": 1` を入れる（形を変えたときに古いデータと見分けるため）
- レシピは URL で見分ける。YouTube は `https://www.youtube.com/watch?v=<動画ID>` の形にそろえる
- 日付は `2026-10-03`、日時は ISO 8601（例：`2026-10-03T19:00:00+09:00`）
- 真偽値の項目名は `isFavorite` のように `is` で始める

### 重みの考え方

- **チャンネル**：`sources.json` の `weight` の比率で選ばれます（合計が100でなくても構いません）
- **動画**：まだ「作る」を選んでいない動画 `1`、選んだことがある動画 `0.2`、お気に入り `0.5`
- 最近（14日以内）「作る」を選んだ動画、「作らない」とした動画、使わない食材・調味料を含む動画は選ばれません
- 食事ごとのジャンルの条件に合わない動画も選ばれません（下記）
- 3分以下の動画（ショート動画）と、概要欄に分量の表記（`大さじ`、`200g` など）が3つ未満の動画は、レシピ動画ではないとみなして選ばれません

### 使わない食材の登録について

キーワードと除外は、文字列がそのまま含まれるかで判定します。表記の揺れがありそうなものは、両方とも登録してください。

```json
"avoidIngredients": ["にんにく", "ニンニク"]
```

### 常備している食材の登録について

`pantryIngredients` に登録した食材は、レシピのメイン食材に入りません。メイン食材は、買い物で用意が必要な食材の目安にもなるためです。

```json
"pantryIngredients": ["にんにく", "しょうが", "小ねぎ"]
```

- 常備していても、メイン食材として出てきてほしいものは、あえて登録しません（例：長ねぎを常備していても、買い忘れると致命的なので敢えて外すなど）
- メイン食材は Claude が判断して選ぶので、表記の揺れ（生姜 / しょうが）は片方だけ登録すれば足ります
- 登録を変えても、すでに記録したレシピのメイン食材は変わりません

### ジャンルの登録について

ジャンルごとに言葉を登録し、食事ごとに「そのジャンルだけ」か「そのジャンルを外す」かを決めます。判定はタイトルだけで行います。概要欄の宣伝文やハッシュタグで、関係ない動画まで外れるのを防ぐためです。

```json
"avoidTitleKeywords": ["ケーキ", "プリン"],
"genres": {
  "noodles": ["パスタ", "麺", "そば"],
  "bread": ["食パン", "トースト"]
},
"meals": {
  "lunch":  { "onlyGenres":  ["noodles", "bread"] },
  "dinner": { "avoidGenres": ["noodles", "bread"], "avoidTitleKeywords": [] }
}
```

- `onlyGenres`：そのジャンルの言葉をどれか含む動画だけが候補になります
- `avoidGenres` と食事ごとの `avoidTitleKeywords`：その食事のときだけ外します。一番外側の `avoidTitleKeywords` はいつでも外します
- 食事は `--meal` で選び、省略すると `dinner` です
- 「パン」のように短い言葉は「フライパン」などにも一致するので、「食パン」「トースト」のように具体的に書きます
