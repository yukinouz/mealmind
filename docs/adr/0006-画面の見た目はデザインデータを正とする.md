# 0006. 画面の見た目はデザインデータを正とする

- 日付: 2026-10-10
- 状態: 採用

## 背景

Web アプリの画面デザインは、Claude のキャンバス「MealMind 画面デザイン」で作っています。色・文字・余白などの値は、デザインデータとコード（`web/src/_styles/_variables.scss` など）の両方にあり、放っておくと食い違います。

## 決定

- 色・文字・余白・部品の見た目は、デザインデータを正とします
- 食い違いに気づいたときは、デザインに合わせてコードを直します
- 見た目は、ふつうはデザインデータを先に直してからコードに反映します。実装しながら調整したほうが早いときは、先にコードを直してもよいですが、そのあと必ずデザインデータにも反映します
- デザインデータの場所と、アートボードとコードの対応は `web/README.md` に書きます

## 理由

- デザインはコードより先に進んでおり、見た目の検討はキャンバスで行っています
- 正を1つに決めておけば、食い違ったときにどちらを直すか迷いません

## 影響

- デザインデータは非公開なので、リポジトリだけを見た人は見た目の決まりを確かめられません
- コードを先に直したときは、デザインデータへの反映を忘れると食い違いが残ります。反映するまでは、その変更を仕上がったとみなしません
