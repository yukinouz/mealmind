# 0012. 提案元は YouTube チャンネルだけにする

- 日付: 2026-10-12
- 状態: 採用

## 背景

提案元にはクラシルもありましたが、個別のレシピを選ぶにはサイトの検索が必要で、Web の画面では提案されていませんでした（[0009](0009-画面の提案は抽選スクリプトで複数件まとめて選ぶ.md)）。

## 決定

- 提案元は YouTube チャンネルだけにし、クラシルの処理（抽選・スキルでの検索・記入例）を削除します
- レシピサイトを加えるときは、改めて検討します

## 理由

- スキルと画面で提案元がそろい、抽選の決まりを1通りにできます
- 使わない分岐を残すと、スクリプトとスキルの手順が複雑なままになります

## 影響

- [0003](0003-動画一覧を保存しスクリプトで抽選する.md)・[0009](0009-画面の提案は抽選スクリプトで複数件まとめて選ぶ.md)・[0011](0011-料理の系統は材料とメイン食材と一緒に埋める.md) のクラシルについての記述は、当時の内容です
