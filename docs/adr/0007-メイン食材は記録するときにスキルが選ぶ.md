# 0007. メイン食材は記録するときにスキルが選ぶ

- 日付: 2026-10-10
- 状態: 採用

## 背景

レシピ一覧では、レシピごとにメイン食材をタグで見せ、タグを押すと同じ食材のレシピに絞り込みます。`recipes.json` の `ingredients` は材料をそのまま写したもので、調味料や注記を含み、同じ食材でも書き方がそろっていません（「豚バラ」「豚バラ薄切り肉」「豚バラブロック肉」など）。

## 決定

- `suggest` スキルが「作る」を記録するときに、メイン食材を最大3つ選び、`mainIngredients` に記録します
- 名前は部位まで分け、切り方・銘柄・注記を外します。すでに記録した名前と同じ食材なら、その名前を使います
- 調味料・ご飯・常備している食材（`preferences.json` の `pantryIngredients`）は入れません。麺とパンは入れます
- 薬味は、常備していなければ少しだけ使うときも入れます。メイン食材は、買い物で用意が必要な食材の目安にもなるためです

## 理由

- 書き方の揺れや注記、付け合わせの料理の材料を見分けるのは、決まった一覧よりも Claude の判断のほうが確実です
- 判断はスキルで行うという運用（ADR-0001）に合います

## 影響

- スキルを通さずに記録したレシピには、`mainIngredients` が付きません
- 選び方は Claude の判断なので、同じ料理でも記録した時期によって選び方が少し変わることがあります

## 検討した他の案

- **Web のコードで振り分ける**：調味料の一覧や言い換えの一覧を手で増やし続ける必要があるため見送りました
