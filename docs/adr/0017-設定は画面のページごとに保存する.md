# 0017. 設定は画面のページごとに保存する

- 日付: 2026-10-24
- 状態: 採用

## 背景

チャンネル・提案のしかた・好み・食事とジャンルは、これまで JSON を手で編集していました。これを `/settings` 以下の画面から編集できるようにします。

## 決定

- 設定は画面から編集し、各ページで「保存する」を押したときにまとめて書き込みます。未保存のまま別のページへ移ろうとしたら確認を出します
- チャンネルの割合（`sources.json` の `weight`）は、データも画面も合計100にそろえます。画面では `weight` をそのまま % として見せ、合計が100のときだけ保存できます。抽選スクリプトの重みの扱い（比率で選ぶ）は変えません
- ジャンルのキーは日本語の名前にします（`"麺類": ["パスタ", ...]`）

## 理由

- 割合を % として見せると、画面とデータの値が同じになり、換算がいりません。スクリプトは比率で選ぶので、手で編集して合計がずれても動きます
- ジャンルの名前をキーにすると、名前をそのまま画面に出せて、抽選スクリプトの仕組みを変えずに済みます
