# 0008. 除外したレシピもレシピの情報をすべて持つ

- 日付: 2026-10-10
- 状態: 採用

## 背景

レシピ一覧から外したレシピや、提案で「作らない」を選んだレシピを、非表示のレシピのページから作るレシピに戻せるようにします。これまでの `excluded.json` は URL・タイトル・提案元・日時だけを持っていたため、戻すと材料や「作る」を選んだ日が失われていました。

## 決定

- `excluded.json` の1件は、`recipes.json` と同じ項目を持ちます
- 加えて、外した日時 `excludedAt` と理由 `reason` を持ちます。`rejected` は提案で「作らない」を選んだもの、`hidden` は作るレシピから外したものです
- 作るレシピから外すときは、情報を持ったまま `recipes.json` から `excluded.json` へ移します。戻すときは逆に移します
- 画面では今のところ `rejected` と `hidden` を区別しません

## 理由

- 情報を持ったまま移せば、戻したときに元どおりになります
- `rejected` と `hidden` は意味が違うので、今は画面で区別しなくても、記録だけは残しておけば後から区別できます

## 影響

- 「作らない」を記録するときも、材料とメイン食材を書き出す必要があります
- 提案で「作らない」を選んだレシピは「作る」を選んだ日がないため、`chosenDates` は空になります

## 検討した他の案

- **`recipes.json` に残して印を付ける**：提案で「作らない」を選んだ、一度も作っていないレシピまで `recipes.json` に入ることになり、「作ると決めたレシピ」という意味がぶれるため見送りました
