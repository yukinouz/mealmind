# 0016. 抽選の設定を個人データに移す

- 日付: 2026-10-24
- 状態: 採用

## 背景

抽選の設定（`settings.json`）は、公開リポジトリの `data/` に置いていました（[0013](0013-個人データは非公開リポジトリに置きWeb起動時に同期する.md)）。これを設定画面から変えられるようにします。

## 決定

- `settings.json` は `mealmind-data` に置き、`data/personal/settings.json` から読みます
- 公開リポジトリには、記入例の `data/settings.example.json` だけを置きます。ファイルがなければ、抽選は既定値で動きます

## 理由

- 画面から変えるたびに、公開リポジトリに差分が出るのを避けるためです
- 設定の値は好みによるもので、ほかの個人データと同じ扱いが合います

## 影響

- [0013](0013-個人データは非公開リポジトリに置きWeb起動時に同期する.md) の「`settings.json` は `mealmind` の `data/` に置く」は、この ADR で置き換えます
