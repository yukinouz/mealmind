# 0009. 画面の提案は抽選スクリプトで複数件まとめて選ぶ

- 日付: 2026-10-11
- 状態: 採用

## 背景

Web のトップで、提案するレシピを5件まとめて出したくなりました。一方、`suggest` スキルは会話で1件ずつ提案する使い方を続けます。Web の画面はスキルを使わず、`scripts/pick-recipe.sh` を直接実行しています。

## 決定

- `pick-recipe.sh` に `--count` を足し、重ならないように複数件を1回の実行で選びます。`--count` がないときの動きは変えません
- `--count` のときは YouTube だけから選び、クラシルは外します

## 理由

- 抽選の決まり（重み・除外）を、スキルと画面で1か所にまとめられます
- クラシルは個別のレシピを選ぶのにサイトの検索が必要で、画面にはその仕組みがありません

## 影響

- 画面ではクラシルのレシピが提案されません。扱いは後で決めます

## 検討した他の案

- **画面用の別スキルを作る**：画面からスキルを呼ぶ仕組みがないため見送りました
- **画面からスクリプトを5回呼ぶ**：重ならないように順番に呼ぶ必要があり、5件で約2秒かかるため見送りました（`--count` なら約1秒）
