# ADR（Architecture Decision Record）

設計上の決定を、その理由と一緒に1件ずつ記録します。

## 書き方

- 仕様は README に書きます。ADR にするのは、README に書けない理由や見送った案が、将来の見直しで必要になる決定だけです
- ファイル名は `NNNN-決定を短く表す日本語.md`（空白なし）にします。一覧は作らないので、ファイル名だけで内容が分かるようにします
- 番号は増やす一方で、使い回しません
- 決定を変えるときは元の ADR を書き換えず、新しい ADR を作ります。元の ADR の状態を「〇〇で置き換え」に変えます
- 状態：`提案中` / `採用` / `廃止` / `〇〇で置き換え`

```markdown
# NNNN. タイトル

- 日付: YYYY-MM-DD
- 状態: 採用

## 背景

## 決定

## 理由

## 影響

## 検討した他の案
```
