# 0013. 個人データは非公開リポジトリに置き、Web の起動時に同期する

- 日付: 2026-10-12
- 状態: 採用（`settings.json` の置き場所は [0016](0016-抽選の設定を個人データに移す.md) で置き換え）

## 背景

`mealmind` は公開リポジトリのため、個人データ（レシピの記録・好み・提案元）は git の対象外にしていましたが、個人データを保管する方法を検討していました。

## 決定

- 個人データは非公開リポジトリ `mealmind-data` に置き、`data/personal` からフォルダごとリンクします
- `npm run dev` の直前（`predev`）に `scripts/sync-personal-data.sh` が、コミット → 取り込み → 送信をします
- 記入例（`*.example.json`）と `settings.json` は、今まで通り `mealmind` の `data/` に置きます

## 理由

- コードとデータがどちらも GitHub にあり、変更の履歴も残ります
- 同期はすぐでなくてよいので、Web の起動時で足ります。手で push しなくて済み、リポジトリの中で完結します
- 保存処理は一時ファイルに書いてから置き換えるため、ファイルごとのリンクは置き換えのときに外れます。フォルダごとのリンクなら外れません

## 影響

- スキルだけで記録した変更は、次に Web を起動するまで GitHub に送られません

## 検討した他の案

- **Google Drive で同期を続ける**：履歴が残らず、複数の端末で同時に使うと競合コピーができやすいため見送りました
- **launchd や gitwatch で自動 push する**：Mac 全体の設定が必要になり、リポジトリの中で完結しないため見送りました
