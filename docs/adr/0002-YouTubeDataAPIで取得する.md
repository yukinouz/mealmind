# 0002. YouTube の情報は YouTube Data API で取得する

- 日付: 2026-10-03
- 状態: 採用

## 背景

提案には、登録したチャンネルの動画一覧と、材料が書かれた概要欄が必要です。AI の記憶だけで提案させると、存在しない URL を作ってしまう危険があります。

## 決定

YouTube Data API v3 を API キーで使います。

| 用途 | API | 消費 |
|---|---|---|
| ハンドルからチャンネルIDを調べる | `channels.list` | 1単位 |
| 動画一覧（概要欄の全文を含む）を50件ずつ取得 | `playlistItems.list` | 1単位 |
| 動画の長さを50件ずつ取得（ショート動画の判定用） | `videos.list` | 1単位 |

- チャンネルのアップロード動画一覧の ID は、チャンネル ID の先頭 `UC` を `UU` に置き換えたものです
- 公開情報を読むだけなので、OAuth（Google アカウントでのログイン連携）は使いません

## 理由

- 公式の手段なので安定しています
- 料金はかからず、1日 10,000 単位の上限内で十分足ります（全チャンネルの一覧と長さの取得で約280単位）
- アプリ化しても同じ方法を使えます
- `playlistItems.list` で概要欄の全文が取れます。長さだけは含まれないので、`videos.list` でまとめて取得します

## 影響

- Google Cloud でのプロジェクト作成と API キーの管理が必要です（[0004](0004-APIキーは承認済みスクリプトだけで使う.md)）
- キーワード検索の `search.list` は1日100回までの別枠です。今は使っていません

## 検討した他の案

- **yt-dlp**：準備は簡単ですが、YouTube 側の変更で動かなくなることがあり、アプリ化したときにも使いにくいため見送りました
- **Web 検索とページ取得**：YouTube のページはうまく読めないことが多く、概要欄の全文が取れる保証がないため見送りました
