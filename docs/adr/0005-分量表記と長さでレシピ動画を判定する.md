# 0005. レシピ動画は概要欄の分量表記と動画の長さで判定する

- 日付: 2026-10-03
- 状態: 採用

## 背景

チャンネルには、レシピ以外の動画（商品レビュー、お知らせ、雑談、店舗の密着企画など）も含まれます。また、材料の書き方はチャンネルごとに違います。

| チャンネル | 書き方の例 |
|---|---|
| リュウジ | `キャベツ...600g` |
| コウケンテツ | `・小松菜：1束（200g）` |
| だれウマ | `牛乳　200ml` |
| 賛否両論 | `鶏もも肉 1枚、トマト1個、…` |
| 桝谷 | `・パスタ…160g` |

## 決定

- 概要欄に、分量を表す言葉（`大さじ`、`小さじ`、`適量`、`少々`、`ひとつまみ`、`200g` や `1個` のような数字＋単位）が **3つ以上** ある動画をレシピ動画とみなします
- そのうえで、**3分以下**の動画はショート動画として外します

## 理由

- 書き方はばらばらでも、分量の言葉はどのチャンネルにも共通して出てきます
- 「材料」という見出しは、チャンネルによっては書かれていません
- ショート動画は長尺動画の切り抜きなので、元の長尺動画が候補に残れば十分です。ただし、ショートにも長尺動画の概要欄がそのまま付いていることがあり（リュウジ）、分量表記だけでは外せません

## 影響

- 判定結果：リュウジ 2,790 / 3,790、コウケンテツ 652 / 780、だれウマ 1,186 / 1,440、賛否両論 385 / 678、桝谷 268 / 283
- 2024年10月より前の3分以下の動画（約20本）は通常の動画ですが、ルールを単純にするため一緒に外しています
- トマトの飾り切りのように、料理ではない動画もレシピと判定されることがあります。今は「作らない」で外しています
