# 0003. 動画一覧を手元に保存し、抽選はスクリプトで行う

- 日付: 2026-10-03
- 状態: 採用

## 背景

5チャンネルで約7,000本、合計約20MBの動画一覧があります。提案のたびに API で取得するのは無駄が多く、AI が一度に全部読むにも大きすぎます。

## 決定

- `scripts/fetch-videos.sh` で動画一覧を取得し、`data/cache/videos-<id>.json` に保存します（目安は週1回）
- `scripts/pick-recipe.sh` が条件で絞り込んで1件だけを選び、AI はその1件だけを読みます
- `data/cache/` は再取得できるので、git の対象外にします

## 理由

- 実際に取得した一覧からしか選ばないので、存在しない URL を提案しなくなります
- 提案のたびに API を使わずに済みます
- AI が読む量が1件分で済みます
- AI はランダムに選ぶのが苦手で、選択が偏りがちです。乱数もスクリプトで作ります

## 影響

- 新しい動画は、一覧を取得し直すまで候補に入りません
- クラシルは一覧を保存しないので、選ばれたときはサイトの検索結果ページを WebFetch で取得します。トップページのレシピは JavaScript で読み込まれるため取得できず、検索に使う言葉がないときはクラシルを抽選から外します
