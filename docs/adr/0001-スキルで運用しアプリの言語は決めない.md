# 0001. 当面は AI エージェントとスキルで運用し、アプリの言語は決めない

- 日付: 2026-10-03
- 状態: 採用

## 背景

将来、機能を広げてアプリ化する可能性があります（公開はせず、個人で使う前提）。ただし、まずは使い方を固めることを優先したいです。

## 決定

- 当面は Claude Code のスキル（`.claude/skills/<名前>/SKILL.md`）と対話して運用します
- アプリ用のプログラミング言語やフレームワークは、まだ決めません
- 確実さが必要な処理（API の呼び出し、抽選など）だけは、macOS に標準で入っている `bash` と `jq` のスクリプトにします

## 理由

- 画面や言語は後から入れ替えられますが、使い方とデータの形は引き継がれます。先に固めるべきなのはこちらです
- AI が苦手な処理（正確な乱数、大量データの絞り込み）だけをスクリプトに任せれば、追加のインストールなしで確実に動きます

## 影響

- スクリプトは macOS 標準の bash 3.2 でも動くように書く必要があります（空の配列の扱いなど）
- アプリ化するときは、スクリプトの処理をアプリのコードに置き換えます

## 検討した他の案

- **最初から言語を決めてアプリを作る**：使い方が固まる前に作り込むことになるので見送りました
