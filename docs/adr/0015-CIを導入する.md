# 0015. CI を導入する

- 日付: 2026-10-14
- 状態: 採用

## 背景

`web/` の lint・型チェック・テストは、手で実行しないと結果が分かりませんでした。

## 決定

- GitHub Actions で、`web/` の lint・型チェック・テストを自動で実行します
- ワークフローは役割ごとにファイルを分けます（`lint-typecheck.yml`・`test.yml`）
- 外部の Actions は、コミットのハッシュで固定します

## 理由

- ファイル名で役割が分かります
- タグは後から別のコミットに付け替えられますが、ハッシュは中身ごとに決まるため、タグを乗っ取られても影響を受けません

## 検討した他の案

- **1つのファイル・1つのジョブにまとめる**：設定の重複はなくなりますが、ファイル名から中身が分からないため見送りました
- **Actions を `@v7` のようにタグで指定する**：修正版を自動で取り込めますが、タグを乗っ取られると影響を受けるため見送りました
