# 0010. 画面で記録したレシピの材料とメイン食材はレシピを見せるページを開いたときに埋める

- 日付: 2026-10-11
- 状態: 採用

## 背景

トップで提案したレシピの「作る」「作らない」を、画面から記録します。ただし記録には、材料（`ingredients`）とメイン食材（`mainIngredients`）が要ります（ADR-0007・ADR-0008）。これらは動画の説明文を読んで決める必要があり、これまでは `suggest` スキルの Claude が決めていました。画面の処理だけでは決められません。

## 決定

- 画面では、材料とメイン食材を空にして記録します
- 材料とメイン食材が空のレシピがあれば、そのレシピを見せるページを開いたときに `claude -p` でまとめて埋めます。`recipes.json` はレシピ一覧（`/recipes`）、`excluded.json` は非表示のレシピのページです。一覧は待たずに表示し、埋まったらタグを出します
- 説明文に材料がないときは、空のまま埋めたことにします
- Claude には、説明文と選び方の決まりを渡し、決めた形の JSON を返させるだけにします（`--tools ""`・`--json-schema`）。ファイルに書くのは Web です
- 選び方の決まりは1つのファイルにまとめ、`suggest` スキルと Web の両方から読みます
- モデルは既定のモデルを使います

## 理由

- 食材タグを使うのはレシピを見せるページなので、開いたときに埋めれば足ります。スキルで埋める操作を覚えておく必要がありません
- Claude がファイルを書かなければ、画面の書き込みとぶつからず、ツールの許可も要りません
- 試したところ、1件あたり約7秒で、既定のモデルはスキルと同じ材料とメイン食材を返しました。Haiku は安いものの、材料の名前を書き換えました

## 影響

- `claude` コマンドとそのログインが、Web を動かす環境に必要です
- 埋めるまでの間、画面で記録したレシピには食材タグが出ません

## 検討した他の案

- **スキルを使ったときに埋める**：画面でできることとスキルでできることを、使い分けて覚えておく必要があるため見送りました
- **ボタンを押したときに埋める**：空のレシピはあまり溜まらないので、開くたびに自動で埋めても負担が小さいと判断しました
- **Claude にファイルを書かせる**：画面の書き込みとぶつかるうえ、ツールの許可を決める必要があるため見送りました
- **キーワードの一覧でメイン食材を選ぶ**：ADR-0007 と同じ理由で見送りました
