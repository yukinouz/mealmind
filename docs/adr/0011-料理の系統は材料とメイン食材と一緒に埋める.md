# 0011. 料理の系統は材料とメイン食材と一緒に埋める

- 日付: 2026-10-11
- 状態: 採用

## 背景

レシピ一覧で、ジャンル（和食・洋食・中華・その他）で絞り込みます。ただし、レシピのデータにはジャンルの項目がありません。動画のタイトルだけでは、ジャンルを決められないことが多くあります。

## 決定

- レシピに `cuisine`（`washoku` / `yoshoku` / `chuka` / `other`）を足します。画面では「ジャンル」と表示します
- 決め方は `prompts/record-ingredients.md` に書き、材料・メイン食材と同じく Claude が決めます。`suggest` スキルは記録するときに、Web はレシピを見せるページを開いたときに（ADR-0010）埋めます
- すでに材料とメイン食材があるレシピには、`cuisine` だけを足します

## 理由

- 料理名・調味料・作り方から決めるのは、言葉の一覧で振り分けるより Claude の判断のほうが確実です（ADR-0007 と同じ理由）
- 埋める仕組みがすでにあるので、新しい呼び出しを増やさずに済みます

## 影響

- クラシルのレシピは、スキルを通さずに記録すると `cuisine` が付きません。説明文がないため、Web では埋められません
- 初めて開いたときは、記録済みのレシピをまとめて埋めるので時間がかかります（17件で約70秒）

## 検討した他の案

- **タイトルの言葉で振り分ける**：外れることが多く、言葉の一覧を増やし続ける必要があるため見送りました
- **項目名を `genre` にする**：`preferences.json` の `genres`（麺・ご飯もの・パン）と紛らわしいため見送りました
